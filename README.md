# Nexxa Wireframe

Original Toyota production planning prototype, preserved as the before version for a before-and-after comparison.

Open `index.html` or serve this folder with `python3 -m http.server 8767 --bind 127.0.0.1`. The N logo returns to the overview.

This is a static prototype with fictional data and simulated actions. No build step is required. Inter is loaded from Google Fonts.
